# 서울대 관악캠퍼스 현장답사 지도

[휴대폰에서 지도 열기](https://kji3216-hash.github.io/snu_map/)

기존 20개 조사 후보를 실제 측정할 41개 조각으로 나누고 완만한 대조 구간 2개를 추가했습니다. 조사할 길 자체를 필수 경유하도록 동선을 구성해, 양 끝 사이의 지름길로 빠지던 17번 등의 누락을 바로잡았습니다.

| 회차 | 측정 구간 | 조사·연결 이동 거리 |
| --- | ---: | ---: |
| 예비답사 · 중앙권 | 7 | 약 0.94km |
| A · 남쪽 공대권 | 24 | 약 3.83km |
| B · 중앙·기숙사·북측 | 19 | 약 4.65km |

예비답사는 B 회차와 기록을 공유합니다. 접근·귀가·현장 우회 거리는 별도입니다.

지도에서 구간을 선택한 뒤 A·B를 확인하고, 시작·중간·끝의 각도를 각각 3번 기록합니다. 경사가 바뀌면 측정 지점을 추가합니다. 사진 설명, 인도·계단·턱·출입 제한도 기록하고 완료 상태를 지도에서 확인할 수 있습니다.

입력은 **현재 브라우저에만 자동 저장**됩니다. 서버로 전송하거나 기기 간 자동 동기화하지 않습니다. 회차 종료 시 **CSV와 JSON을 모두 내려받아 보관**하세요. JSON 가져오기는 같은 구간 ID의 기존 기록을 덮어쓰지 않습니다. 사진 원본은 갤러리에 따로 보관합니다.

온라인에서 처음 열어 ‘오프라인 준비됨’을 확인하고, 출발 전 실제 휴대폰의 비행기 모드에서 재접속을 시험하세요. HTML에 지도 자료와 D3 코드가 포함되어 외부 지도 타일·스크립트가 필요하지 않습니다. GPS는 HTTPS 주소에서 사용자가 ‘내 위치’를 눌러 권한을 허용할 때만 켜지며 기기에서만 표시됩니다.

SRTM 30m 기반 수치는 추정 평균입니다. 현장 각도로 계산한 길이 가중 평균도 근사치이며, 부호가 있어 오르막과 내리막이 상쇄될 수 있습니다. 지점별 값과 관측 최대 경사를 함께 확인하세요. 연결선의 실제 통행 가능 여부는 현장에서 확인해야 합니다.
