지도 사용안내와 데이터 설명
작성: 2026-10-26

1. 휴대폰에서 사용
https://kji3216-hash.github.io/snu_map/
‘예비답사’를 먼저 선택 → 구간 목록/지도 번호를 눌러 선택 → A·B 확인 → 측정·사진·통행 조건 입력 → 완료.
‘이 구간’은 현재 구간 확대, ‘회차 전체’는 전체 동선이다. +/−, 드래그, 두 손가락 확대도 사용할 수 있다.
실선은 조사할 길, 점선은 연결 이동 후보다. 내 위치 버튼은 사용자가 허용할 때만 GPS를 켠다.
GPS는 기기에서만 표시하며 백업·CSV·서버로 보내지 않는다. 건물 안·지하에서는 오차가 크므로 현장 표지를 우선한다.

2. 저장·백업
- 입력은 구간 ID를 키로 이 브라우저의 localStorage에 저장된다. GitHub에는 관측값을 업로드하지 않는다.
- 새로고침·같은 주소 재접속 시 기록을 불러온다. 사생활 보호 모드·브라우저 데이터 삭제에 의존하면 기록이 사라질 수 있다.
- CSV: 분석용. 측정 지점마다 한 행, 원시 각도 3개, 방향, 거리, 계산 경사, 현장 조건을 포함한다.
- JSON: 복원용. 모든 구간 기록, 측정 지점, 준비/조사자 정보를 보관한다.
- 가져오기는 같은 구간 ID의 기존 기록을 덮어쓰지 않는다. 충돌은 보존한 구간 수로 알려준다.
- 같은 구간을 다시 측정하려면 먼저 JSON을 백업한다. 완료 기록을 수정하면 ‘기록 중’으로 바뀌고 완료 버튼을 다시 눌러야 한다.
- 사진은 갤러리에 따로 보관한다. 이 지도에는 파일명·설명만 저장한다.
- 기기마다 기록이 다르므로 회차 종료 때 CSV와 JSON을 모두 보관한다. 여러 조사자의 중복 구간은 별도 원본 파일로 보존한다.

3. 오프라인
- 인터넷이 되는 상태에서 접속해 ‘오프라인 준비됨’을 확인한다. 이는 이 브라우저의 캐시 준비 상태다.
- 출발 전 비행기 모드에서 주소를 다시 열어 지도·기록이 보이는지 확인한다. 기종별 캐시 유지 여부는 실제 휴대폰에서 확인해야 한다.
- ‘오프라인용 HTML 받기’의 단일 파일에는 지도 자료와 D3 코드가 들어 있다. 배경 타일·외부 폰트를 내려받지 않는다.
- 파일 열기 지원은 휴대폰 브라우저/파일 앱마다 다르므로 기본 사용 방식은 기존 GitHub 주소다.
- 파일 주소와 웹 주소, 서로 다른 브라우저는 저장 공간이 다를 수 있다. JSON으로 옮긴다.
- 카카오/OSM 원본 링크는 인터넷이 필요하다.

4. 측정과 분석
- 기본 지점은 실제 측정 방향의 시작·중간·끝이다. 거리는 그 시작점에서 누적한 m이다.
- A·B는 원본 길의 좌표 방향이며 실제 진행 방향과 별개다. 측정 전에 실제 방향을 고른다.
- 각도 3개를 각각 tan(각도)×100으로 바꿔 지점 경사 평균을 구한다.
- 지점별 경사를 거리 순으로 사다리꼴 적분하고 길이로 나눈 근사 평균을 구한다.
- B→A로 측정했으면 부호를 뒤집어 모든 구간 평균을 A→B 기준으로 맞춘다.
- 추정값과 차이는 %p다. 부호가 포함된 평균은 상하 경사가 상쇄될 수 있다.
- 최대값은 관측한 각도 중 절댓값이 가장 큰 경사이며, 평균과 별도다. JSON에는 별도 최대 각도 원시값도 있다.
- 미측정은 빈칸/null, 실제 평지는 0이다. 불가 구간을 경사 0으로 채우지 않는다.
- CSV의 status는 complete / unavailable / in_progress, direction은 A→B / B→A다.
- kind는 기존 OSM 자료의 분류이며, 현장 기록이 이를 자동 수정하지 않는다.
- source_hash는 원본 추정경사 GeoJSON의 SHA-256이다. 지도 자료가 달라지면 기존 기록의 버전을 확인해야 한다.
- 도면·배리어프리 시설 자료는 이전 프로젝트에 그대로 보존되어 있다. 이 도구의 경사 측정 대상은 기존 OSM 보행망이다.

5. 파일 위치와 재생성
13_현장답사_웹지도/dist/index.html: 게시할 완성 지도
13_현장답사_웹지도/dist/offline.html: 동일 내용을 담은 오프라인 파일
13_현장답사_웹지도/src/: 앱·측정 계산·스타일·서비스워커 원본
13_현장답사_웹지도/tests/measurement.test.cjs: 계산·검증·기존 기록 보존 시험
06_분석코드/현장답사_실행지도_만들기.py: 기존 자료에서 실행계획과 HTML 재생성
05_시각화_수정용소스/현장답사_실행지도_템플릿.html: 문서 틀
03_가공데이터/서울대_현장답사_실행계획.json: 43개 대상·회차·필수 경유 좌표
04_지도시각화/서울대_현장답사_실행지도.html: 로컬 실행본
09_웹배포/: 기존 GitHub 배포 폴더에도 새 지도를 반영한다.
이전버전/: 기존 지도와 덮어쓰기 방지 수정 전 생성 코드 보관

프로젝트 폴더에서 실행:
python3 06_분석코드/현장답사_실행지도_만들기.py
node 13_현장답사_웹지도/tests/measurement.test.cjs

새 생성기는 관측 CSV/JSON을 생성·덮어쓰지 않는다. 기존 생성기도 기록양식이 있으면 보존하도록 수정했다.
새 지도 갱신에는 새 생성기를 사용한다. 예전 생성기는 예전 지도 출력용이며 새 웹지도를 대체할 수 있다.
